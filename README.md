# Sara Quiz · Examen 100

Web estática (HTML + CSS + JS vanilla) con exámenes tipo test de 100 preguntas, derivada del motor de
`sara-quiz-forestal`. Cada intento baraja preguntas y opciones; historial en localStorage.

Todas las preguntas se basan exclusivamente en el temario de la oposición y llevan su cita literal de
origen, verificada automáticamente por `tools/validar_integridad.py` (ver `CLAUDE.md`).

Activar el guardián tras clonar: `git config core.hooksPath .githooks`
